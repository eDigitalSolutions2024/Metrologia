Proceso de generación del certificado de calibración

Del Reporte de Servicio al PDF firmado. Todo se opera desde el detalle del Reporte.

flowchart TD

subgraph CAT["Catálogo · se prepara una vez"]
  direction TB
  P1["Alta de Patrón"]:::cat
  P2{"¿Certificado del patrón
en PDF digital?"}:::dec
  P3["Leer certificado (PDF)
La IA precarga: U, k, unidad, intervalo,
resolución, trazabilidad, laboratorio,
N° de certificado, fecha, periodicidad"]:::cat
  P4["Capturar a mano
(PDF escaneado o sin IA)"]:::cat
  P5["Revisar y Guardar patrón
El PDF queda adjunto"]:::cat
  TT["Plantilla de Tolerancia
puntos nominales + EMP"]:::cat
  TU["Plantilla de Incertidumbre
contribuciones GUM / EA-4/02"]:::cat
  P1 --> P2
  P2 -- "Sí" --> P3 --> P5
  P2 -- "No" --> P4 --> P5
end

A["Cliente / Cotización aprobada"]:::ini --> B["Crear Reporte de Servicio"]:::rep
B --> C["Asignar equipo al Reporte
Técnico + Patrones + Plantilla de Tolerancia"]:::rep
P5 -. "patrón disponible" .-> C
TT -. "precarga puntos" .-> C

C --> D{"¿La asignación
tiene patrón?"}:::dec
D -- "No" --> D1["Aviso: sin trazabilidad.
Editar asignación y agregar el patrón correcto"]:::warn
D1 --> C
D -- "Sí" --> E["Botón: Iniciar calibración"]:::rep

subgraph POP["Popup «Iniciar calibración» · un solo formulario"]
  direction TB
  F["Datos del servicio
razón · tipo · procedimiento"]:::cal
  G["Condiciones ambientales
temperatura · humedad"]:::cal
  H["Magnitud → Tipo de instrumento → Plantilla"]:::cal
  I["Puntos de calibración
nominal · unidad · EMP (precargados)"]:::cal
  J["Modo: Único  /  Como se encontró – Como se dejó"]:::cal
  K["Capturar lecturas por punto
chip PASA / NO PASA en vivo"]:::cal
  L["Guardar y enviar a revisión"]:::cal
  F --> G --> H --> I --> J --> K --> L
end

E --> F
TU -. "arma el presupuesto" .-> H

L --> M["Motor GUM: crea un cálculo de incertidumbre
por cada punto y condición"]:::sys
M --> N["Calibración = Terminada
(automático)"]:::sys

N --> O["Calidad: «Aprobar y autorizar certificado»
aprueba todos los cálculos en bloque"]:::qa
O --> P["Certificado = Autorizado"]:::sys
P --> Q["«Emitir certificado»
vigencia + quién revisó + quién autorizó"]:::qa
Q --> R["Documento con folio + QR
snapshot de equipo, cliente y patrones
Certificado = En revisión"]:::sys

R --> S{"Calidad revisa el PDF"}:::dec
S -- "Todo bien" --> U["«Aprobar certificado»
Certificado = Vigente"]:::qa
S -- "Algo mal" --> T["«Rechazar» + motivo
anula el documento
Calibración vuelve a Pendiente"]:::rej
T --> V["Técnico: «Editar calibración»"]:::cal
V --> L

U --> W["Ver / descargar certificado (PDF)"]:::fin
W --> X["Entrega del equipo"]:::fin
X --> Y["Finalizar Reporte"]:::fin
